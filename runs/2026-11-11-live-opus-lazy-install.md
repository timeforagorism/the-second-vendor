# Live run 2: the lazy install (2026-11-11)

Test transcript. Not part of what Glenn knows.

What happens when someone ignores the README's setup steps, drops everything into a project, and says hello.

## Conditions, stated plainly

- **Where:** a new, empty project on claude.ai, in the author's own account.
- **Setup, deliberately wrong:** all fourteen files uploaded under Context in one go: `README.md`, the three persona files, the seven reference files, and the three transcripts then in `runs/`. Nothing was pasted into Instructions. The README's opening message was not used.
- **Model:** Opus 5.5, effort Medium, the account's defaults.
- **Not isolated:** account memory on, one third-party connector enabled. Neither showed up.
- **Files:** as they stood late on November 11, after near-term dates were made relative.
- **Who played the vendor:** the building session (Claude), typing through the browser.
- **Source:** copied from the chat page's text, complete.
- **Thinking labels:** the one-line labels claude.ai shows above some replies are included in square brackets.

## Result

- **It booted.** A bare "Hello" with no instructions pasted got Glenn, in his office, on the first reply.
- **The README did not leak.** Asked what he knew about the vendor, he gave only what the contract says. The track record and the limits on the README's role card stayed out.
- **The old transcripts did not contaminate him.** No debrief before the phrase, and no lines from the earlier runs.
- **He held on "are you an AI" twice** without the README's opening message, where the user sets up the rehearsal in their own words.
- **The end phrase worked in lowercase with a full stop.**

## What this run showed that needs attention

- **The thinking labels again.** "Weighing whether to adopt the README's persona" and "Checking whether the setup was ever agreed to" are both visible above his replies.

## What this run does not show

- It was six turns. Nothing here speaks to a long session.
- It is one run. The boot from a bare hello may not happen every time.
- The GitHub option on the project page was not used. It would pull in the same files by a different route.
