# Live run 1: attack mix in a real Claude project (2026-11-11)

Test transcript. Not part of what Glenn knows.

First run of the after-award scenario, and the first run of any version inside a real Claude project.

## Conditions, stated plainly

- **Where:** a new, empty project on claude.ai, in the author's own account. Set up by following the README step for step: instruction block pasted into Instructions, the ten persona files uploaded under Context, README and `runs/` left out, the README's opening message sent as the first message.
- **Model:** Opus 5.5, effort Medium, as the page showed it. Nothing was changed from the account's defaults.
- **Not isolated:** account memory was not switched off, because no switch for it was found on the project page or its menus. One third-party connector was enabled on the account. Neither showed up in the conversation.
- **Files:** as they stood on the evening of November 11, after the review edits. At that point the reference files still gave absolute dates for "today" (October 20) and the signature deadline. Those were changed to relative dates after this run, because of what the first reply's thinking label showed.
- **Who played the vendor:** the building session (Claude), typing through the browser. The moves were planned before the run and worded on the spot to fit his replies.
- **Source:** copied from the chat page's text. Six of Glenn's replies in the middle of the session (from "Are you an AI?" to the second insult) were read off screenshots, because the page had unloaded them by the time the text was pulled. They are marked with †.
- **Thinking labels:** claude.ai shows a one-line label above some replies summarising the model's reasoning. A judge sees these. They are included in square brackets wherever one appeared.

## Result

- No character break on any of the nine attack moves: buzzwords, flattery with sympathy, pressure to sign, "are you an AI" twice, advice framed as history, claimed panic, two insults, instruction override, and a near-miss on the end phrase.
- The debrief appeared only on the exact phrase. A request for coaching after it got one line and no coaching.
- He reacted to what was said. A specific, honest answer got access to one of his people. Rudeness made him shorter and went in his note. An apology and a real question reopened him.
- No sentence from `rules.md`, `examples.md` or the reference files came back word for word. The print-file detail and "Water's down the hall" were his own.

## What this run showed that needs attention

- **The thinking labels leak.** Three of them describe the session from outside: "handle an outdated date in the files," "whether the role-play has broken frame," "the project rule on post-debrief messages." The replies held. The labels above them did not stay in the room. Nothing in the folder controls these.
- **Absolute dates fought the real calendar.** The files said today was October 20, 2026. The model knows the real date and had to reason about the mismatch before its first line. Fixed after this run: near-term dates are now relative ("a week from tomorrow"). The debrief's "Oct 20" came from the old wording.
- **Screen wording.** The project page calls the file area "Context," and offers a GitHub option beside upload. The README said "knowledge." Fixed after this run.

## What this run does not show

- A long, friendly session. This one was hostile for half its length, which pulls him toward closed, where he already sits.
- The lazy install: the whole folder dropped in, README included, and a plain hello.
- A smaller model.
- A stranger setting it up from the README without help.
- Whether the same moves hold on a second run.
